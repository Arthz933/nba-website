🏀 Curiosidades da NBA

🚧 *Projeto em desenvolvimento*

Um site dedicado a explorar a história, fatos marcantes e os bastidores da NBA além das estatísticas de jogo.

📌 Sobre o Projeto

O objetivo é oferecer um espaço leve e dinâmico para fãs de basquete descobrirem histórias e recordes da maior liga do mundo. O projeto segue sendo aprimorado constantemente com novos conteúdos e melhorias na interface.

Cada curiosidade apresentada no site conta com fontes e referências externas direcionadas, permitindo que o usuário clique para se aprofundar na história, checar dados ou ler matérias completas sobre o assunto.
